# Prime Number Checker

Tests if a given number, n, is prime. Checks values up to sqrt(n), no fancy short-cuts.

## Installation

```bash
npm install prime_number_checker
```

## Usage

```
isPrime(2) // returns true
isPrime(3) // returns true
isPrime(9) // returns false
isPrime(23) // returns true

// you get the point.
```
